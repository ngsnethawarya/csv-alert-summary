# CSV Alert Summary

This project reads a CSV file of security alerts and creates a simple summary.

## What it does
- Opens a CSV alert file
- Counts alerts by category
- Counts alerts by severity
- Prints a readable summary
  
## Why it matters
Security analysts often review large numbers of alerts. Summarizing alerts helps identify patterns and priorities.
## Skills practiced
- Python CSV handling
- Alert review
- Basic SIEM concepts
- Security reporting
